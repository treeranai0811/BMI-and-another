# เว็บคำนวณสุขภาพ (Health Calculator)

เว็บแอปภาษาไทยสำหรับคำนวณค่าสุขภาพพื้นฐาน 5 รายการ ได้แก่ **BMI, BMR, BSA, BF และ IBW** โดยกรอกข้อมูลร่างกายแล้วกดคำนวณ ระบบจะแสดงผลทันที

*A Thai-language web app that calculates BMI, BMR, BSA, body fat % and ideal body weight. Built with Java, Spring Boot and Vaadin Flow.*

## ฟีเจอร์

| หน้า | Route | ข้อมูลที่ต้องกรอก | ผลลัพธ์ |
|------|-------|-------------------|---------|
| หน้าแรก | `/` | - | ข้อความต้อนรับและปุ่มเริ่มคำนวณ |
| ดัชนีมวลกาย (BMI) | `/bmi` | น้ำหนัก, ส่วนสูง | ค่า BMI และเกณฑ์ที่อยู่ในช่วงไหน |
| อัตราการเผาผลาญพลังงาน (BMR) | `/bmr` | น้ำหนัก, ส่วนสูง, อายุ, เพศ | พลังงานที่ร่างกายใช้ขณะพัก (กิโลแคลอรี) |
| พื้นผิวของร่างกาย (BSA) | `/bsa` | น้ำหนัก, ส่วนสูง | พื้นที่ผิวกาย (ตารางเมตร) |
| เปอร์เซ็นต์ไขมันในร่างกาย (BF) | `/bf` | น้ำหนัก, ส่วนสูง, อายุ, เพศ | เปอร์เซ็นต์ไขมัน (%) |
| น้ำหนักที่ควรจะเป็น (IBW) | `/ibw` | ส่วนสูง, เพศ | น้ำหนักที่เหมาะสม (กิโลกรัม) |

ความสามารถอื่นๆ

- ตรวจสอบข้อมูลก่อนคำนวณ ถ้าช่องว่าง เป็นศูนย์ หรือติดลบ จะแสดงกรอบสีแดงพร้อมข้อความให้กรอกใหม่
- ผลลัพธ์แสดงในกรอบสีเขียว
- มีเมนูด้านบนสำหรับสลับไปยังหน้าคำนวณอื่นได้ทันที
- ปุ่ม "เสร็จสิ้น" กลับไปหน้าแรก

## สูตรที่ใช้

หน่วยที่รับเข้า: น้ำหนักเป็นกิโลกรัม ส่วนสูงเป็นเซนติเมตร อายุเป็นปี

| ค่า | สูตร |
|-----|------|
| **BMI** | น้ำหนัก ÷ (ส่วนสูงเป็นเมตร)² |
| **BMR** (Harris–Benedict) | ชาย: `66 + (13.7 × น้ำหนัก) + (5 × ส่วนสูง) − (6.8 × อายุ)`<br>หญิง: `655 + (9.6 × น้ำหนัก) + (1.8 × ส่วนสูง) − (4.7 × อายุ)` |
| **BSA** (Mosteller) | √(น้ำหนัก × ส่วนสูงเป็นเซนติเมตร ÷ 3600) |
| **BF** | ชาย: `(1.2 × BMI) + (0.23 × อายุ) − 16.4`<br>หญิง: `(1.2 × BMI) + (0.23 × อายุ) − 5.4` |
| **IBW** (Broca) | ชาย: ส่วนสูง − 100<br>หญิง: ส่วนสูง − 105 |

เกณฑ์การแปลผล BMI ที่ใช้ในโปรแกรม

| BMI | ผลการประเมิน |
|-----|--------------|
| ต่ำกว่า 18.5 | ผอม หรือน้ำหนักต่ำกว่ามาตรฐาน |
| 18.5 ถึงต่ำกว่า 22.9 | สมส่วน หรืออยู่ในเกณฑ์ปกติ |
| 22.9 ถึงต่ำกว่า 24.9 | น้ำหนักเกิน หรืออ้วนระดับ 1 |
| 24.9 ถึงต่ำกว่า 29.9 | อ้วน หรืออ้วนระดับ 2 |
| 29.9 ขึ้นไป | อ้วนอันตราย หรืออ้วนระดับ 3 |

> ผลลัพธ์เป็นค่าประมาณเพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำทางการแพทย์

## เทคโนโลยีที่ใช้

- **Java 17**
- **Spring Boot 3.4.3**
- **Vaadin Flow 24.6.5** สร้างหน้าเว็บด้วยโค้ด Java ล้วน ไม่ต้องเขียน HTML/JavaScript เอง
- **Maven** (มี Maven Wrapper 3.9.9 มาให้ ไม่ต้องติดตั้ง Maven แยก)

หมายเหตุ: ใน `pom.xml` มี Spring Data JPA และ H2 Database รวมอยู่ด้วย แต่ตอนนี้โปรแกรมยังไม่ได้เก็บข้อมูลลงฐานข้อมูล

## โครงสร้างโปรเจกต์

แต่ละค่าที่คำนวณแยกเป็น 2 คลาส คือคลาส UI (หน้าเว็บ) และคลาส Calculator (ตรรกะการคำนวณ) โดยทุก Calculator สืบทอดจากคลาสแม่ `Body`

```
demo/
├── pom.xml
├── mvnw / mvnw.cmd                  # Maven Wrapper
└── src/main/
    ├── java/com/example/demo/
    │   ├── DemoApplication.java     # จุดเริ่มต้นของ Spring Boot
    │   ├── HomeView.java            # หน้าแรก  (route: /)
    │   ├── Body.java                # คลาสแม่ (abstract) เก็บน้ำหนัก ส่วนสูง และเมธอด calculate()
    │   ├── BMI.java                 # หน้า UI ของ BMI   (route: /bmi)
    │   ├── BMICalculator.java       # คำนวณ BMI
    │   ├── BMR.java                 # หน้า UI ของ BMR   (route: /bmr)
    │   ├── BMRCalculator.java       # คำนวณ BMR
    │   ├── BSA.java                 # หน้า UI ของ BSA   (route: /bsa)
    │   ├── BSACalculator.java       # คำนวณ BSA
    │   ├── BF.java                  # หน้า UI ของ BF    (route: /bf)
    │   ├── BFCalculator.java        # คำนวณ BF
    │   ├── IBW.java                 # หน้า UI ของ IBW   (route: /ibw)
    │   └── IBWCalculator.java       # คำนวณ IBW
    └── resources/application.properties
```

## วิธีรันโปรแกรม

**สิ่งที่ต้องมี:** JDK 17 ขึ้นไป และต่อเน็ตในการรันครั้งแรก (เพื่อดาวน์โหลดไลบรารี)

1. ดาวน์โหลดหรือ clone โปรเจกต์นี้ แล้วเปิด Terminal ที่โฟลเดอร์โปรเจกต์ (โฟลเดอร์ที่มีไฟล์ `pom.xml`)
2. สั่งรัน

   Windows
   ```
   mvnw.cmd spring-boot:run
   ```
   macOS / Linux
   ```
   ./mvnw spring-boot:run
   ```
3. เปิดเบราว์เซอร์ที่ <http://localhost:8080> (โปรแกรมตั้งค่าให้เปิดเบราว์เซอร์ให้เองอยู่แล้ว)

การรันครั้งแรกอาจใช้เวลาหลายนาที เพราะ Vaadin ต้องเตรียมไฟล์ฝั่งหน้าเว็บ ครั้งต่อไปจะเร็วขึ้น

**ถ้าต้องการสร้างไฟล์ `.jar` สำหรับใช้งานจริง**

```
./mvnw clean package -Pproduction
java -jar target/demo-0.0.1-SNAPSHOT.jar
```

**เปลี่ยนพอร์ต:** แก้ `server.port` ในไฟล์ `src/main/resources/application.properties` (ค่าเริ่มต้นคือ 8080)
